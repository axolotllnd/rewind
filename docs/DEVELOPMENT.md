# Разработка и сборка

REWIND — Windows x64-приложение на Electron, React и FFmpeg. Исходники не содержат пользовательских настроек, записей и содержимого рабочего каталога `work`.

## Требования

- Windows 10 2004+ x64.
- Node.js 24.11+ или 22.18+; сборка подготовлена на Node.js 24 и pnpm 11.25.0.
- pnpm 11.25.0 (зафиксирован в `packageManager`).
- .NET Framework C# compiler: `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Inno Setup 6.7.4 или новее для установщика.

## Команды

```powershell
pnpm install --frozen-lockfile
pnpm run build:native
pnpm run build:sounds
pnpm run build
pnpm run test:code
pnpm start
```

Установка зависимостей загружает платформенные Electron и FFmpeg. Разрешение install-скриптов ограничено Electron, esbuild и ffmpeg-static в `pnpm-workspace.yaml`.

`pnpm dev` поднимает Vite на localhost; запись в браузерном предпросмотре недоступна. `pnpm start` открывает готовую Electron-сборку, поэтому сначала нужен `pnpm run build`.

```powershell
pnpm run package
pnpm run installer
```

`package` создаёт `outputs/REWIND-<version>/`. `installer` упаковывает эту папку в один `.exe` и создаёт SHA-256. Если компилятор Inno Setup не найден автоматически:

```powershell
$env:ISCC = 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
pnpm run installer
```

## Структура

| Каталог | Назначение |
| --- | --- |
| `src/` | Интерфейс, редактор, локализация, совместимый захват, обработка звука плеера |
| `electron/` | Основной процесс, IPC, буфер, сохранение, аудио, обработчики биндов и уведомления |
| `native/` | Исходники C# для WASAPI, списка DXGI-дисплеев и общих сочетаний клавиш |
| `assets/` | Иконки, шрифты из зависимостей и оригинальные звуковые ресурсы |
| `installer/` | Сценарий Inno Setup и оформление установщика |
| `scripts/` | Сборка, упаковка и вспомогательные проверки |
| `tests/` | Проверки кода, FFmpeg и дополнительные Windows-сценарии |
| `third-party/` | Лицензия и сведения о поставляемой сборке FFmpeg |

`assets/native/*.exe` генерируются из C# и не хранятся в Git. Звуки можно заново создать `pnpm run build:sounds`; оформление установщика создаёт `scripts/installer-art.ps1`.

## Основные процессы

Интерфейс не управляет записью кадров. Захват H.264 на поддерживаемом устройстве выполняет отдельный FFmpeg-процесс Desktop Duplication + NVENC. Совместимый вариант использует скрытое окно захвата. WASAPI-помощники передают PCM по локальному соединению в кодирование аудио.

Буфер разбивается на фрагменты. Сохранение защищает нужные фрагменты от удаления, ждёт покрытия всех дорожек и публикует готовый файл атомарным переименованием. MP4 использует перепаковку; точный MKV/WebM может потребовать кодирования. Нажатия имеют собственные временные метки и проходят через очередь.

Обычные сочетания регистрирует Electron. Если комбинация занята другим приложением, `HotkeyBridge` наблюдает только настроенные сочетания и передаёт событие основному процессу. Он всегда передаёт клавиши дальше по цепочке и не записывает вводимый текст. При вводе нового бинда оба обработчика REWIND приостанавливаются.

Уведомление имеет отдельное окно. `setContentProtection(false)` вызывается при создании и каждом показе. Встроенная проверка восстанавливает зависшее или аварийно завершённое окно уведомлений.

Предпросмотр и экспорт работают с оригиналом без его изменения. Общий тракт Web Audio ограничивает пики смеси плеера; FFmpeg ограничивает пики записи и экспорта.

## Проверки

`pnpm run test:code` не управляет окнами. Он использует синтетические медиафайлы, проверяет буфер, границы повторов, сохранение, валидацию, звук и сопоставление клавиш. Перед ним нужно собрать native-помощники.

`pnpm test` дополнительно открывает отдельные тестовые окна, использует захват экрана и выходное аудиоустройство. Микрофон не включается. Интерактивная проверка общего бинда запускается отдельно с `REWIND_TEST_INTERACTIVE=1` и требует нажатий в тестовом окружении. Не запускай полный набор во время важной записи.

Для v0.2.7 выполнены 21 проверка кода; одна интерактивная проверка пропущена. Полный набор 36 проверок выполнялся на предыдущем этапе. Эти числа не означают проверку каждой игры и конфигурации ПК.

## Подготовка изменений

Опиши воспроизведение и ожидаемый результат, добавь проверку для изменения поведения, собери frontend и native-код. Не включай `.env`, настройки, записи, логи, временные файлы и зависимости в коммит. Не публикуй токены в Issues.
