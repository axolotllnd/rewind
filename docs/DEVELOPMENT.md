# Разработка и сборка

REWIND — Windows x64-приложение на Electron, React и FFmpeg. Исходники не содержат пользовательских настроек, записей и содержимого рабочего каталога `work`.

## Требования

- Windows 10 2004+ x64.
- Node.js 24.11+ или 22.18+; сборка подготовлена на Node.js 24 и pnpm 11.25.0.
- pnpm 11.25.0 (зафиксирован в `packageManager`).
- .NET Framework C# compiler: `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Inno Setup 6.7.4 или новее для установщика.

## Команды

```powershell
pnpm install --frozen-lockfile
pnpm run build:native
pnpm run build:sounds
pnpm run build
pnpm run test:code
pnpm start
```

Установка зависимостей загружает платформенные Electron и FFmpeg. Разрешение install-скриптов ограничено Electron, esbuild и ffmpeg-static в `pnpm-workspace.yaml`.

`pnpm dev` поднимает Vite на localhost; запись в браузерном предпросмотре недоступна. `pnpm start` открывает готовую Electron-сборку, поэтому сначала нужен `pnpm run build`.

```powershell
pnpm run package
pnpm run installer
```

`package` создаёт `outputs/REWIND-<version>/`. `installer` упаковывает эту папку в один `.exe` и создаёт SHA-256. Если компилятор Inno Setup не найден автоматически:

```powershell
$env:ISCC = 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
pnpm run installer
```

## Структура

| Каталог | Назначение |
| --- | --- |
| `src/` | Интерфейс, редактор, локализация, совместимый захват, обработка звука плеера |
| `electron/` | Основной процесс, IPC, буфер, сохранение, аудио, обработчики биндов и уведомления |
| `native/` | Исходники C# для WASAPI, списка DXGI-дисплеев и общих сочетаний клавиш |
| `assets/` | Иконки, шрифты из зависимостей и оригинальные звуковые ресурсы |
| `installer/` | Сценарий Inno Setup и оформление установщика |
| `scripts/` | Сборка, упаковка и вспомогательные проверки |
| `tests/` | Проверки кода, FFmpeg и дополнительные Windows-сценарии |
| `third-party/` | Лицензия и сведения о поставляемой сборке FFmpeg |

`assets/native/*.exe` генерируются из C# и не хранятся в Git. Звуки можно заново создать `pnpm run build:sounds`; оформление установщика создаёт `scripts/installer-art.ps1`.

## Основные процессы

Интерфейс не управляет записью кадров. Захват H.264 на поддерживаемом устройстве выполняет отдельный FFmpeg-процесс Desktop Duplication + NVENC. Совместимый вариант использует скрытое окно захвата. WASAPI-помощники передают PCM по локальному соединению в кодирование аудио.

Аппаратное видео передаётся сегментатору через MPEG-TS с исходной временной шкалой, повторяемыми заголовками и меткой discontinuity. При DXGI_ERROR_ACCESS_LOST / E_ACCESSDENIED во время переключения рабочего стола `NativeScreen` пересоздаёт только процесс захвата (задержка 0,5–2 секунды). Входной pipe сегментатора остаётся открытым, аудио и сессия сохраняются. Конкатенация сегментов сохраняет временной разрыв до новых кадров; защищённая поверхность UAC недоступна обычному приложению. Другие ошибки по-прежнему завершаются через обработчик ошибки. Остановка отменяет таймер восстановления.

В FFmpeg 6.1 `DuplicateOutput` → `E_ACCESSDENIED` преобразуется в `AVERROR(EPERM)` и видимый текст `Operation not permitted`, без HRESULT. Поэтому классификатор обрабатывает как числовые коды, так и `Desktop duplication access denied` и отказ **открытия входа** в контексте `ddagrab`. Одна лишь ошибка конфигурации фильтра, разрешения выходного файла или NVENC не переводится в бесконечное восстановление. Это покрыто сообщением из пользовательского отчёта и повторными отказами перед появлением кадров.

Буфер разбивается на фрагменты. Сохранение защищает нужные фрагменты от удаления, ждёт покрытия всех дорожек и публикует готовый файл атомарным переименованием. MP4 использует перепаковку; точный MKV/WebM может потребовать кодирования. Нажатия имеют собственные временные метки и проходят через очередь.

Сочетания обслуживают Electron `globalShortcut` и три источника `HotkeyBridge`: Raw Input (`RIDEV_INPUTSINK`), `WH_KEYBOARD_LL` и резервная проверка состояния назначенных клавиш. Живая проверка 0.2.10 показала отсутствие F10 в WM_INPUT при наличии Alt; Raw Input не считается универсальной заменой перехватчика. Callback раннего обработчика только сопоставляет клавиши, добавляет готовое действие в ограниченную очередь и вызывает `CallNextHookEx`. Отдельный поток объединяет дубликаты и пишет в stdout, защищая hook от задержек IPC. Hook обновляется при смене активного HWND и раз в 5 секунд. Поток резервной проверки смотрит только основные клавиши из конфигурации; состояние модификаторов читается при удержанной целевой клавише. Переназначение при удержании не вызывает ложного нажатия.

Передаются только настроенные действия, а не вводимый текст. `RIDEV_NOLEGACY` / `RIDEV_NOHOTKEYS` не используются. В основном процессе дополнительно объединяются уведомления Electron и помощника. При вводе бинда обработчики приостанавливаются. После сбоя помощника повторный запуск идёт с задержкой до 5 секунд. Встроенное повышение прав не выполняется; поведение при более высоком уровне прав активного окна зависит от ограничений Windows. Диагностика `--diagnostic` выводит только агрегированные счётчики и Alt/F10; обычный запуск её не включает.

Уведомление имеет отдельное окно. `setContentProtection(false)` вызывается при создании и каждом показе. Встроенная проверка восстанавливает зависшее или аварийно завершённое окно уведомлений.

Предпросмотр и экспорт работают с оригиналом без его изменения. Общий тракт Web Audio ограничивает пики смеси плеера; FFmpeg ограничивает пики записи и экспорта.

`app-maintenance.cjs` проверяет latest release через публичный GitHub API, принимает только стабильную числовую версию и точное имя установщика в исходном репозитории с SHA-256. Загрузка идёт в `updates` профиля; частичный файл публикуется переименованием после проверки. Перед запуском хеш проверяется повторно. Renderer не передаёт URL, путь или командную строку на исполнение. IPC для обновления и удаления доступен только главному окну.

Перед передачей управления установщику/деинсталлятору блокируются новые команды, ожидается очередь сохранений, сохраняется непрерывная запись и останавливаются процессы захвата. Неудачное сохранение блокирует выход; ошибка запуска восстанавливает фоновый захват. Inno Setup принимает `/REWINDUPDATE=1` или `/REWINDREMOVE=1`, ожидает выхода предыдущего процесса и не закрывает чужие программы. Только обновление автоматически запускает новую версию после установки. Данные пользователя не входят в список удаления.

## Проверки

`pnpm run test:code` не управляет окнами. Он использует синтетические медиафайлы, проверяет буфер, границы повторов, сохранение, валидацию, звук и сопоставление клавиш. Перед ним нужно собрать native-помощники.

`pnpm test` дополнительно открывает отдельные тестовые окна, использует захват экрана и выходное аудиоустройство. Микрофон не включается. Интерактивная проверка общего бинда запускается отдельно с `REWIND_TEST_INTERACTIVE=1` и требует нажатий в тестовом окружении. Не запускай полный набор во время важной записи.

Для v0.2.11 выполнены 44 проверки кода; одна интерактивная проверка пропущена. Проверяются загрузка/отмена/кэш, целостность файла, недопустимые релизы, подготовка сохранений, ошибка запуска, запрет удаления portable/dev и новые переводы. Установщик и удаление не запускались на компьютере пользователя. Проверки DXGI моделируют отказ и проверяют реальным FFmpeg сохранение через разрыв видеопотока. Реальное окно UAC вручную не вызывалось. Эти числа не означают проверку каждой игры и конфигурации ПК.

## Подготовка изменений

Опиши воспроизведение и ожидаемый результат, добавь проверку для изменения поведения, собери frontend и native-код. Не включай `.env`, настройки, записи, логи, временные файлы и зависимости в коммит. Не публикуй токены в Issues.
